# wow-addons
Collection of addons for World of Warcraft

## Done 
- [SlashikWhichDungeonInvite](https://github.com/slashik-mv/wow-addons/blob/main/_release/SlashikWhichDungeonInvite.zip): Prints which dungeon you got invited to (Premade Groups / M+). Support of automatic greetings when joining a party or raid.
- [SlashikChangingLayoutByText](https://github.com/slashik-mv/wow-addons/blob/main/_release/SlashikChangingLayoutByText.zip): Switch layouts from Edit Mode using predefined chat commands: `/l <layoutName>` or `/layout <layoutName>` (e.g., `/l normal` activates the Normal layout). You can list all available commands by using `/l help`
- [SlashikCheckTalentsBeforeMplusOrRaid](https://github.com/slashik-mv/wow-addons/blob/main/_release/SlashikCheckTalentsBeforeMplusOrRaid.zip): automatically checks your talent build when a Ready Check starts in a dungeon or raid. If your active build name doesn’t include the expected keywords (for example “mythic+”, “m+”, “mplus” for Mythic+ or “raid” for raids), it shows a large on-screen warning and a chat message so you can switch builds before the pull. Extended to support entering delves with the keyword “delve”.
- [SlashikRaidBreakTime](https://github.com/slashik-mv/wow-addons/blob/main/_release/SlashikRaidBreakTime.zip): Shows a synced raid-break countdown with a randomly selected illustrated break card. Supports `/break <minutes>` and listens for compatible DBM and BigWigs break timers.
